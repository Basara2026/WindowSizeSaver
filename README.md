# WindowSizeSaver

任意のソフトが起動したときに、あらかじめ登録したウインドウの**位置とサイズ**で自動的に開くようにする、Windows 用の常駐ツールです。

- エクスプローラーをどのフォルダで開いても同じ位置・サイズで開く
- フォルダごと(ウインドウのタイトルごと)に別の位置・サイズを指定する
- メモ帳、Chrome、Firefox などをいつも決まった場所に開く

## 特長

- **通知領域に常駐**します。右クリックメニューは「設定」と「閉じる」の2つだけです。
- **ホットキーで登録**します。位置とサイズを覚えさせたいウインドウの上で `Ctrl` + `Alt` + `Shift` + `S` を押すだけです。
- 「そのソフトの**すべてのウインドウ**」と「**特定のタイトルのウインドウだけ**」を、別々に指定できます。
- 起動直後に自分で位置を戻してしまうソフト(Firefox やエクスプローラーなど)にも対応します。
- 設定画面は Windows の**ダークモード / ライトモード**(Fluent テーマ)に追従します。
- 設定ファイルは実行ファイルと同じフォルダに保存されます。レジストリは使いません。

## 動作環境

- Windows 10 / 11(64bit)。開発と動作確認は Windows 11 で行っています。(Windows 10 での動作は未確認)
- [.NET 10 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/10.0)(x64)

## 使い方

### 1. 起動する

`WindowSizeSaver.exe` を起動すると、通知領域(タスクトレイ)にアイコンが表示されます。

| 操作 | 動作 |
| --- | --- |
| アイコンを左クリック | 設定画面を開く |
| アイコンを右クリック | 「設定」「閉じる」のメニューを表示 |

### 2. ウインドウの位置とサイズを登録する

1. ウインドウを、覚えさせたい位置とサイズに合わせます。
2. そのウインドウをアクティブにした状態で、`Ctrl` + `Alt` + `Shift` + `S` を押します。
3. 設定画面に、次の2行が追加されます。(例として エクスプローラー を登録する場合。追加直後は「有効」がオフです)

| 有効 | プロセス | タイトル | X | Y | 幅 | 高さ | 遅延(ms) |
| :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| □ | explorer.exe | (空白) | 1920 | 360 | 1900 | 1200 | 100 |
| □ | explorer.exe | PC - エクスプローラー | 1920 | 360 | 1900 | 1200 | 100 |

- **タイトルが空白の行**: そのソフトの**すべてのウインドウ**が対象です。有効にすると、エクスプローラーをどのフォルダで開いても、この位置とサイズで開きます。
- **タイトルのある行**: そのタイトルのウインドウ**だけ**が対象です。上の例では、「PC」を開いたときだけ、この位置とサイズで開きます。
- 両方が有効な場合は、**タイトルのある行が優先**されます。

### 3. 有効にする

設定画面で、使いたい行の「有効」にチェックを入れて、**OK**(または**適用**)を押します。押した時点から有効になります。

### 設定画面

| 項目 | 説明 |
| --- | --- |
| 有効 | オンにした行だけが働きます。 |
| プロセス | 対象のプロセス名(実行ファイル名)です。 |
| タイトル | 対象のウインドウのタイトルです。空白は「すべてのウインドウ」を表します。 |
| X / Y | ウインドウの左上の位置(画面左上からのドット数)です。 |
| 幅 / 高さ | ウインドウのサイズ(ドット数)です。 |
| 遅延(ms) | ウインドウが表示されてから、位置とサイズを合わせ始めるまでの待ち時間です。 |
| 削除 | その行を削除します。 |

- X・Y・幅・高さ・遅延は、セルをクリックして直接編集できます。
- 変更は **OK** または **適用** を押した時点で有効になります。**キャンセル**で破棄できます。
- 設定画面の位置・サイズ・列幅は、閉じたときに記憶されます。
- 左下の **スタートアップ登録** にチェックを入れて OK / 適用を押すと、Windows の起動時に自動で起動します。外すと解除されます。

### 遅延について

Firefox やエクスプローラーなどは、ウインドウを表示した直後に、自分で前回の位置へ戻そうとします。そのため、表示と同時に位置を合わせると、そのあとで動かし返されて、ウインドウが行ったり来たりすることがあります。

「遅延」を設定すると、表示されてからその時間だけ待ってから位置を合わせるので、動きが落ち着きます。

- 新しく登録した行の初期値は **100ms** です。
- `firefox.exe` の行だけ、初期値は **1000ms** です。
- 動きが落ち着かないソフトは、遅延を長めにしてみてください。

## 動作のしくみと注意点

- ウインドウが表示されたことを検知して、ルールに合うウインドウの位置とサイズを合わせます。非表示から再表示される常駐ソフトにも、表示のたびに適用します。
- 表示から約4秒間は位置を見守り、ソフト側に動かされたときは合わせ直します。(待ち時間をおいて、最大5回まで)
- 次のどれかを検知すると、そのウインドウの補正をやめます。
  - タイトルバーのドラッグなどで、自分で移動・サイズ変更を始めた
  - ウインドウの近くでマウスをクリックした(スナップレイアウトの操作を含む)
  - ウインドウが前面にある状態で Windows キーを押した
- 最大化された状態で開くソフトは、通常の状態に戻してから合わせます。最小化されたウインドウには触れません。
- 位置は、影を除いた**見た目の枠**を基準にした、物理ピクセルの値です。ディスプレイごとの DPI 設定(Per-Monitor V2)に対応しています。
- **管理者権限で動いているウインドウ**は、通常の権限で起動した本ツールからは動かせません。必要な場合は、本ツールも管理者権限で起動してください。
- ストアアプリなどは、`ApplicationFrameHost.exe` というプロセス名で扱われる場合があります。
- タイトルの空白の行は、そのソフトの**すべての**ウインドウが対象です。たとえばエクスプローラーでは、ファイルコピーの進行状況ウインドウなども同じ位置・サイズになることがあります。

## 設定ファイル

実行ファイルと同じフォルダに、次の2つが作られます。書き込める場所に置いてください。

| ファイル | 内容 |
| --- | --- |
| `WindowSizeSaver.settings.json` | 登録したルール |
| `WindowSizeSaver.ui-settings.json` | 設定画面の位置・サイズ・列幅 |

スタートアップ登録は、現在のユーザーのスタートアップフォルダに、`WindowSizeSaver.lnk` というショートカットを作って行います。登録を外すと、このショートカットを削除します。

## ビルド方法

必要なもの: Visual Studio 2026(「.NET デスクトップ開発」ワークロード)、.NET 10 SDK

1. `WindowSizeSaver.sln` を Visual Studio で開きます。
2. 構成を `Release` / `x64` にして、ビルドします。
